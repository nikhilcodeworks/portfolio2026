# portfolio2026

Modern 3D Interactive Portfolio for UI/UX Designer & Full Stack Creative Developer.

## Tech Stack
- Next.js (App Router)
- React Three Fiber & Three.js (3D Interactive Rotating Earth & Constellations)
- GSAP & ScrollTrigger
- Tailwind CSS & Custom CSS System
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
